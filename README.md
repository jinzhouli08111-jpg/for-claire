# For Claire · 学习小站

一个打开网址就能用的学习工具站，加上一路做出来的几个配套项目。

线上地址：**https://ljz-love-claire.asia**

---

## 网址上有什么

首页是一只张开双爪的小猫，六个功能分别落在它的肉垫上，鼠标移上去会浮出一张说明卡片。

| 功能 | 做什么 | 拿到什么 |
|---|---|---|
| **论文打磨** | 逐段改写：去掉 AI 味、把口语换成学术表达、补上段落之间的论证衔接 | 每一处改动都有「原句 → 改后」对照，最后给三份 A 级版本让你挑 |
| **AI 查重** | 把改前、改后两版摆在一起逐句比对 | 看出哪句只是换了说法、哪句真的降下来了，附一张重复率变化趋势图 |
| **AI 模板** | 说一句你要什么（比如「社团招新海报」）就直接出版式 | 海报、简历、通知、卡片、封面五类模板，可导出 PPT / PDF / Word |
| **智能 PPT** | 边聊边改：告诉它讲给谁听、要几页，先出大纲再排页面 | 每一页都能单独重做，最后导出可编辑的 `.pptx` |
| **思维导图** | 把笔记或大纲粘进去，自动长成树状图 | 拖拽就能调结构和节点，排版自动跟随，可导出图片 |
| **润色翻译** | 中英互译，译完再按中文或英文的表达习惯顺一遍 | 避免翻译腔（正在做，敬请期待） |

另有一个**草稿箱**（`/draft.html`），随手存半成品；首页右上角进去。

几点说明：

- **不用注册、不用装东西**，打开就能用。
- 模型调的是 DeepSeek，Key 只存在 Cloudflare 的 Secret 里，**不会出现在前端**。
- 论文内容只做转发，**不落库、不留存**。

## 主站怎么跑

主站是「一个 Worker 装下整个网站」的结构：所有 HTML 页面在构建时被压成字符串塞进 `worker.js`，部署时只上传这一个文件。

```bash
cd claire-essay-helper-web

# 本地预览（需要一个 key.txt 放 DeepSeek Key）
node server.js          # → http://localhost:8787

# 改完页面后重新打包
node build.js

# 部署到 Cloudflare
npx wrangler deploy
```

几个约定：

- **改页面只改 `*.html` 源文件**，`worker.js` 是 `build.js` 的产物，别手改。仓库里的 `worker.js` 是可直接部署的成品，但改了源码不重新构建，它就会是旧的。
- **`ds.css` 是全站设计系统**：颜色、字阶、间距、圆角、动效、通用组件都在这里，页面只引用 token。
- **换首页小猫图必须换文件名**（如 `cat-hero-v3.webp` → `cat-hero-v4.webp`）：图片响应头是 `immutable`，不换名浏览器会一直用缓存里的旧图。
- **首页六个肉垫热点是按颜色分割算出来的**：先找出每块粉色肉垫的像素重心，再换算成相对图片的百分比坐标。换猫之后必须重新算一遍，否则热点会飘。
- **`key.txt` 不进版本库**（已在 `.gitignore` 里）。线上的 Key 存在 Cloudflare 的 Secret 里。

## 设计基线

全站遵循一套固定的视觉规则，避免各页面各写各的：

- **字体**：Latin 用 Manrope（本地内嵌子集，不走 Google CDN），中文回落到苹方 / 微软雅黑。
- **主色**：`#16a34a`，深色 `#15803d`，底 `#f5f9f6`，墨色 `#1f2a23`。
- **字阶**：12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 / 48 / 60 / 72。
- **间距**：0 / 2 / 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96。
- **圆角**：2 / 4 / 6 / 8 / 12 / 16 / 24 / 999。
- **动效**：`cubic-bezier(0.22, 1, 0.36, 1)`，颜色过渡 300ms，位移过渡 500ms，只动 `transform` / `opacity`。
- **无障碍**：`:focus-visible` 焦点环、skip link、`prefers-reduced-motion` 降级、语义标签与 meta / og 完整。

首页有意保留两处「不合规则」的地方，是刻意为之：Georgia 斜体的品牌字、背景的双层径向光晕。
