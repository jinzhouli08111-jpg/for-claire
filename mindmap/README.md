# 思维导图工作台（MindMap Workbench）

一个**纯前端、零依赖**的思维导图创作工具：中间一个大圈主题，右侧图形库拖到画布上，鼠标拖出连线，
双击图形直接打字，最后导出成 **PPT / Word / PDF** 等格式——其中 PPT 和 Word 里的图形、文字、连线
都是**原生可编辑对象**，打开后能继续改字、拖动、换色、调宽度。

---

## 快速开始

**直接双击 `index.html`** 即可使用（Chrome / Edge 均可）。
不需要 Node、不需要装任何库、不需要联网。

导出的文件：

| 格式 | 是否可编辑 | 说明 |
| --- | --- | --- |
| `.pptx` | ✅ 完全可编辑 | 每个图形是 PowerPoint「形状」，文字在文本框里，连线是可编辑的曲线 |
| `.docx` | ✅ 完全可编辑 | 每个图形是 Word「形状」对象（浮于页面），文字可直接改 |
| `.pdf` | 矢量、文字可选中 | 通过浏览器打印 → 「另存为 PDF」生成 |
| `.svg` | 矢量 | 可在 Illustrator / Figma 继续编辑 |
| `.png` | 位图（2 倍高清） | 适合直接分享 |
| `.json` | 工程文件 | 可重新导入继续编辑（也自动存浏览器本地） |

## 操作说明

### 1. 建图形
- **从右侧「图形库」拖**图形到画布（拖拽时画布上会出现虚线预览）
- 第一个「**无框图形**」是默认图形：只有文字、没有边框，适合做思维导图的主题文字；
  画布上它会显示成「马赛克底纹 + 浅虚线」，方便看见位置、点选、双击改字，但**导出（PPT / Word / SVG / PNG / PDF）时一定是无框的纯文字**；
  想要边框，选中后在右侧属性面板把「形状」换成圆角矩形 / 椭圆等即可
- 或**双击**图形库里的图形，直接加在画布中央
- 双击画布空白处，快速新建一个节点（默认就是无框图形）
- 内置 20 种图形：**无框图形（文字框，默认）**、椭圆/正圆、圆角矩形、矩形、菱形、六边形、八边形、三角形、平行四边形、梯形、
  五边形、五角星、十字、右箭头、燕尾箭头、云朵、文档、圆柱……

### 2. 连线条
- 选中图形后，图形四边会出现 **4 个圆点锚点**，从锚点**拖到另一个图形**即可连线
- 拖到**空白处**松手：会自动新建一个节点并连好（画思维导图最快的姿势）
- 点击连线 → 右侧属性面板里可选：
  - 走线形式：**直线 / 折线 / 曲线**
  - 线型：**实线 / 虚线 / 点线**
  - 箭头：起点 / 终点可分别开关
  - 颜色、粗细
  - 端点吸附位置（自动 / 上 / 下 / 左 / 右）
  - 「反向」按钮可调换起止

### 3. 打字
- **双击图形**直接输入（`Shift+Enter` 换行，`Enter` 或点空白处确认，`Esc` 取消）
- 文字会自动换行、自动缩小字号以适配图形
- 也可以在右侧属性面板里改文字、字号、加粗、对齐、颜色

### 4. 调整
- 拖动图形移动；拖动**四角手柄**缩放
- `Shift+拖动` 框选多个图形，可批量对齐/删除
- 滚轮缩放，空白处拖动平移（中键 / `Alt+拖动` 也可以平移）
- 右侧属性面板可改：形状、填充色、描边色、描边粗细、文字颜色/字号/加粗/对齐、宽高坐标

### 5. 草稿箱与清空
- 顶栏「**草稿箱**」：点一下就把**当前状态**原样存进草稿箱，并打开草稿箱面板
  - 每份草稿带缩略图、标题、时间、图形/连线数量
  - 「取回」= 恢复到画布（当前内容会先进撤销栈，`Ctrl+Z` 可回到取回前）
  - 「删除」清理不要的草稿；最多保留 20 份，最新的排在最前面
  - 内容与最新一份完全相同时只更新时间，不会堆重复条目
- 顶栏「**清空**」：一键清空画布（图形 + 连线）；清空后 `Ctrl+Z` 可撤销，也可去草稿箱取回

### 6. 排版与整理

- 顶栏「**自动排版**」：一键整理成左右分支的经典思维导图布局
- 「**新建中心主题**」：在画布中央加一个深蓝大圈（并把字号调好）
- 「**适应**」：自动缩放到刚好显示全部内容
- 顶栏「**撤销 / 重做**」，最多 120 步

## 导出成 PPT / Word 为什么能继续编辑

文件是在浏览器里**直接按 Office Open XML 标准拼出来的**（自己实现了 zip 打包 + DrawingML 绘制指令），
不是截图、不是转 PDF 再转回去：

- 图形 → `<a:prstGeom>` 预设几何（ellipse / roundRect / diamond / hexagon / cloud / star5 …），
  PowerPoint 里就是标准形状，可以改节点形状、拖控制点
- 文字 → `<p:txBody>` / `w:txbxContent` 文本框，双击即可改
- 连线 → `<a:custGeom>` 自定义几何路径，曲线是真正的三次贝塞尔，支持虚线、点线、箭头
- 每个对象都保留原有位置、尺寸、颜色、字号、加粗

导出的 PPT 幻灯片尺寸会按导图的长宽比自动设置，PDF 也是同一套矢量内容。

## 实现要点

- **无框架、无构建、无第三方库**，双击 `index.html` 就能跑，方便离线使用和二次修改
- 图形路径全部自己算（`shapes.js`），文字排版用 canvas `measureText` 逐字测量，中英文都能正确断行
- 连线端点会吸附到图形边框（椭圆/菱形按真实轮廓计算），曲线控制点沿锚点法线方向生成
- 撤销栈存 JSON 快照，一次拖动/一次属性修改 = 一步
- 自动保存到 `localStorage`，下次打开接着用
- 无框图形在画布、SVG、PPTX、DOCX 四处都按"只输出文字、不画填充与描边"处理

## 已知限制

- PDF 走浏览器打印（「另存为 PDF」），文字仍然是矢量和可选中的；要一把出 PDF 且不改文件名，可用
  Chrome/Edge 的「另存为 PDF」目标并勾选「不再询问」
- PPT / Word 中曲线是**自由曲线**，在 Office 里拖动节点后连线不会自动跟随（可手动拖端点）；
  这一点和原生"连接符"略有差别，但换来的是导出的图形位置与画布完全一致
- 字体使用「微软雅黑」，如果打开文件的电脑没有该字体，Office 会自动替换
- Word 导出的页面尺寸按导图大小设置（最大 22 英寸），图形是浮于页面的形状，不随文字流换行
